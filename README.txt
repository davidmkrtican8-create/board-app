Доска репетитора. Запуск на своём компьютере: ADMIN_KEY=ваш_пароль node server.js  (нужен Node.js 18+)
Кабинет преподавателя: http://localhost:3000/t
Установка на свой сервер (Ubuntu 24.04 / Debian 12): bash <(curl -fsSL https://raw.githubusercontent.com/davidmkrtican8-create/board-app/main/install.sh)
Переменные: ADMIN_KEY (пароль), PORT, HOST, DATA_DIR (папка данных).
Файлы pdf.min.mjs и pdf.worker.min.mjs нужны для просмотра сборников задач (pdf.js, Apache-2.0).
